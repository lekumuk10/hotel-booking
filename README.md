## Pre-requisites
Ensure latest node is installed. Tested on node v24.18.0

---
## Setup
1. Extract to desired folder
2. cd into main project folder (chy)
3. Run `npm install; npm audit fix`
4. Run `npm run dev` to spin local server
5. Visit local server

---

## Troubleshooting
In case anything is not working well like blank pages etc. I always send the whole node modules folder to shakahola.
`rm -rf node_modules` then we restart the setup from step 3.
Images may also be problematic, so I'd use a stock photo repos like pexels or unsplash choice is yours.# hotel-booking
